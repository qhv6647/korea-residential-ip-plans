## 住宅 IP、原生 IP、双 ISP，三句话讲完

住宅 IP 是注册在家庭宽带运营商名下的地址。平台查 Whois 看到的是 KT 这类家宽 ISP，而不是机房段，风控系统眼里的「物种」就不一样。

原生 IP 指 IP 的注册地和服务器实际所在地一致，不会出现「标着韩国、实际落在美国机房」这种一眼假的情况。

双 ISP 更进一步：IP 的 ASN 归属和实际承载网络都来自家宽运营商，可信度比单纯的机房 IP 高一档。LisaHost 官方页面写的是「韩国本土宽带运营商原生住宅静态 IP」，但没有披露具体上游是哪家运营商——这点后面会再说，先记住它没公开。

### 那什么时候该买代理池，不买 VPS

这是两条完全不同的路线，别混着比价。

住宅代理池按流量计费、IP 会轮换，适合需要几十上百个不同 IP 的场景：数据采集、广告验证、比价、SEO 排名监测、多账号各绑一个独立出口。以 Datafuel 的韩国资源为例，住宅 IP 20 万出头、移动 IP 两千多、静态 ISP IP 九千多个（挂在 KT 名下），住宅 $4.50/GB 起，静态 ISP $4.00/IP/月起，粘性会话最长 24 小时，有免费试用且不需要信用卡。

VPS 则是一台独享固定 IP 的完整机器：IP 不变、能装软件、能跑服务，适合长期养同一个账号。**一个账号长期运营 → VPS；几十个账号各要独立 IP，或者只是短期采数据 → 代理池。** 想两边都试试的，代理池有免费试用，先用它验证目标平台的风控反应，再决定要不要为固定 IP 付月费。
